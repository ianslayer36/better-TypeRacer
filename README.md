# Better-TypeRacer

This is a Chrome-based extension for TypeRacer that enhances the site’s appearance and gives it a cleaner, more modern look.

# How to Install
Extract the .zip file.
Open your Chrome-based browser and go to chrome://extensions.
Enable Developer Mode.
Click Load unpacked and select the extracted extension folder.

That’s it — enjoy!
